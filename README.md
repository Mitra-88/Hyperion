# Hyperion - Hypixel Skyblock

## Description
Hyperion is a plugin inspired by the [Hyperion](https://wiki.hypixel.net/Hyperion) sword and its abilities from [Hypixel Skyblock](https://wiki.hypixel.net/Main_Page).

## Features
- **Wither Impact**: Teleport 10 blocks ahead of you. Then implode, dealing 20,000-50,000 damage to all enemies within a 6-block radius. Also applies the wither shield scroll ability, reducing damage taken and granting an absorption shield for 5 seconds.

## Usage
### Installation
1. Download the latest stable release from [here](https://github.com/Mitra-88/Hyperion/releases/latest).
2. Drop the JAR into `plugins/`
3. Start the server
4. Edit `plugins/Hyperion/config.yml` if desired
5. Done.

## In-Game

| Command           | Description                       | Permission            |
|-------------------|-----------------------------------|-----------------------|
| `/givehyperion`   | Gives the player a Hyperion.      | givehyperion.give     |
| `/hyperionreload` | Reloads the plugin configuration. | hyperionreload.reload |

> **Note:** No permissions are required. Any player can obtain and use the Hyperion
